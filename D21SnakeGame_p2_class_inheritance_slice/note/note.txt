Turtle Graphics me Inheritance ka Concept (Score/food Example)

Core Concept:

Jab hum class Score(Turtle) likhte hain, toh iska matlab hai ki Score class khud ek Turtle ban chuki hai. Hume alag se t = Turtle() banakar t.goto() ya t.penup() likhne ki zaroorat nahi padti. Score ke paas Turtle ke saare methods directly mil jaate hain via self.
