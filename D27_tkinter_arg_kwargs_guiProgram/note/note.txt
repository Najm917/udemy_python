        Tkinter
1.  Tkinter (short for Tk interface) is Python's standard, built-in library used for creating Graphical User Interfaces (GUIs)—windows, buttons, text fields, and desktop applications.

2.  It comes pre-installed with standard Python, meaning you do not need to run pip install to use it.

Key Concepts in Tkinter
----------------------------------------
1.  Widgets: The graphical components added to the window, such as:

a.  Label :– Displays text or images.

b.  Button :– Clickable button that triggers actions.

c.  Entry :– Single-line text input field.

d.  Text :– Multi-line text input field.
---------------------------------------
2.  Geometry Managers (Layout): How widgets are positioned:

a.  .pack() – Stacks widgets vertically or horizontally

b.  grid() – Places widgets in a 2D table of rows and columns

c.  place() – Positions widgets using exact $(x, y)$ coordinates.
-------------------------------------
3.  Event Loop (mainloop): An infinite loop that waits for user interactions (clicks, key presses) and updates the screen.

*args = Function ko unlimited values lene deta hai aur unhe ek Tuple ke roop mein store karta hai. (*any)

1.  returen Tuple()

e.g:---
def add(*args):
   sum=0
   for n in args:
       sum+=n
   returen sum
print(add(1,3,4,5,6,7,8,.....))
---------------------------------------
**kwargs:-----
**kwargs Python ka syntax hai jo function ko unlimited keyword arguments (key=value format) lene ki aazadi deta hai.

1.  returen Dictionary {}

e.g:----
def student_info(**kwargs):
    print(kwargs)
    for key, value in kwargs.items():
        print(f"{key}: {value}")
student_info(name="Arif", age=20, city="Delhi")
